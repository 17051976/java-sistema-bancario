# Sistema Bancário em Java

Projeto desenvolvido durante meus estudos de Java com o objetivo de praticar os fundamentos da linguagem e compreender, na prática, a utilização de métodos `void`, classes, objetos, estruturas condicionais e estruturas de repetição.

## Sobre o projeto

O projeto simula um sistema bancário simples executado pelo terminal.

O usuário precisa realizar uma autenticação antes de acessar o menu principal. Após a validação, é possível consultar o saldo, realizar depósitos, realizar saques e encerrar o programa.

## Funcionalidades

* Autenticação de conta, nome e senha
* Menu de operações
* Consulta de saldo
* Depósito
* Saque
* Encerramento do programa
* Validação de opções inválidas
* Repetição de operações utilizando `while`

## Conceitos praticados

Durante o desenvolvimento, foram utilizados:

* Classes e objetos
* Métodos `void`
* `Scanner`
* Variáveis e tipos primitivos
* `String`
* Operadores relacionais e lógicos
* `if` / `else`
* `while`
* `equals()`
* Manipulação de variáveis
* Organização do código em diferentes classes

## Estrutura

O projeto possui três classes principais:

### `Principal`

Responsável pela execução do programa e pelo fluxo das operações bancárias.

### `Validate_Account`

Responsável pela entrada e validação dos dados de acesso.

### `Menu`

Responsável pela exibição das opções disponíveis ao usuário.

## Objetivo

Este é um projeto de estudos desenvolvido para transformar conceitos teóricos de Java em uma aplicação prática executada via terminal.

O projeto representa uma etapa inicial da minha evolução no desenvolvimento backend com Java.
